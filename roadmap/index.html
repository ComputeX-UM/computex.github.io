// PARTICIPANT_GUIDE & ROADMAP

The ComputeX Roadmap

ComputeX isn't a rigid curriculum—it's a launchpad. Whether you're here to explore concepts across domains or build portfolio-ready code, you control your path. No prerequisites, no locked tracks, zero pressure.

// 01. PARTICIPATION_FRAMEWORK
Exploratory Workshop

Conceptual & Architecture

  • ▸ Focus: System architecture, math foundations, "under the hood" mechanics, and ethics.
  • ▸ Requirement: No laptop or code environment needed.
  • ▸ Experience: Sit back, learn concepts, and join the discussion.
Applied Workshop

Hands-On & Implementation

  • ▸ Focus: Writing syntax, leveraging APIs, building pipelines, and using tools.
  • ▸ Requirement: Bring a laptop with VS Code / Python / Git.
  • ▸ Experience: Live coding and leaving with a working project artifact.
⚡
Mix & Match Anytime: You can attend an Exploratory workshop in Health on Tuesday and an Applied workshop in Tech on Thursday. You are never locked into one format or pillar!
