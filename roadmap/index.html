// MAIN EVENT

Weekly Workshops

Our workshops are held on Monday evenings from 7:30 to 8:30 PM. We cycle through workshops focused on each of our five pillars, with occasional ones that span multiple domains. Depending on what fits the topic, each workshop takes on either an applied or exploratory approach. Click through below to see examples of each approach!

These workshops are more focused on exploring the topic and getting familiar with it, and can range from presentations to discussions to open debates depending on the subject!

// Sample Topics
ETHICS + IMPACT

Data Center Infrastructure

Analyzing the environmental cost, power constraints, and resource allocation trade-offs behind global AI compute hubs.

HEALTH + MEDICINE

Medical Imaging Mechanics

Exploring how raw signal scans are processed into diagnostic images using computer vision and reconstruction algorithms.

BUSINESS + STRATEGY

Recommendation Algorithms

Deconstructing consumer data loops, collaborative filtering, and how feed optimization drives user engagement.

These workshops emphasize the hands-on aspect (bring your laptop!), ensuring that you physically type code or play with software so that you walk out with a tangible result!

// Sample Topics
BUSINESS + STRATEGY

DIY Analytics Dashboard

Scraping live web data and rendering interactive visual metrics for market analysis using Python data pipelines.

ART + DESIGN

Unity Interactive Systems

Building a real-time 3D interactive scene from scratch using Unity components, particle effects, and C# scripting.

TECH + ENGINEERING

Pulse Light Sensor Circuit

Breadboarding photoplethysmography (PPG) optical sensors to isolate analog biological signals into pulsing LEDs.
